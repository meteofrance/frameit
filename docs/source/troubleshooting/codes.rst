Look up an error or warning code
================================

Copy the code without the brackets, for example ``E0001``. A code
starting with ``E`` is an error. A code starting with ``W`` is a
warning; check what it means before you use the result.

Use the docs for your FrameIt version. A link such as
``troubleshooting/start.html#e0001`` starts at the root of those docs:
the stable site, the development site under ``develop/``, or your local
HTML build. If a code is not listed, find the symptom in
:doc:`../troubleshooting`.
