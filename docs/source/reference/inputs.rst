Input formats
=============

Use :doc:`../user_guide/input_files` for file selection, times and wind metadata;
:doc:`../user_guide/ocean_netcdf` for NEMO/CROCO grids and quantities; or
:doc:`fa` for native AROME/SURFEX FA.

A supported file format does not establish equivalent quantities or coordinates.
Use the conventions for the producer and layout in your files.
