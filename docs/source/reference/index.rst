Reference
=========

Choose the reference for the question you need to answer:

* **What can I put in the YAML?** Use :doc:`../user_guide/configuration_file`
  for rules/defaults or :doc:`all_keys` for the annotated all-options example.
* **What do my files and outputs mean?** Use :doc:`inputs`,
  :doc:`vertical_levels` and :doc:`../user_guide/output_files`.
* **Which method applies?** Use :doc:`tracking` or :doc:`polar` for inputs,
  equations and limits.
* **Why do apparently similar results differ?** Use :doc:`concepts`;
  for a failed run, use :doc:`../troubleshooting`.

For a worked run, start with the :doc:`task guides <../task_guides/index>`.
